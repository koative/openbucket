# OpenBucket v0.2.2

OpenBucket now passes its live browsing and write tests on Amazon S3, MinIO, RustFS and SeaweedFS as well as Garage, and new connections start from the service you use.

## New

- **Provider** in the connection editor: Amazon S3, Cloudflare R2, Backblaze B2, Wasabi, DigitalOcean Spaces or Hetzner Object Storage fill in the endpoint from the region (for R2, from the account ID). An endpoint you type yourself is never replaced, and saved connections show their provider when edited.

## Fixes

- Custom metadata (`x-amz-meta-…`) shows in the Info panel on services that send the header names capitalized, such as SeaweedFS. Before, it showed as missing there, and editing an object's headers, restoring a version or moving a file over 5 GB removed it.

## Install

Download `OpenBucket-macOS.dmg` from the [website](https://openbucket.koative.com) or the README's **Download for macOS** button, open it, drag OpenBucket to Applications, and launch it from there. Requires macOS 26 or later on Apple silicon or Intel.
