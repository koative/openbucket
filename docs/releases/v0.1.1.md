# OpenBucket v0.1.1

First public macOS preview of OpenBucket, a native browser for Amazon S3 and compatible object stores.

## Highlights

- Connect with a custom endpoint, region, path-style addressing, and an optional known bucket and starting prefix.
- Browse with a grid or sortable list and inspect image, video, and object metadata in the Info panel.
- Preview on demand, download one object, or select files individually for batch download.
- Keep access keys and session tokens in macOS Keychain.
- A refreshed macOS app icon with a full-bleed, opaque background.

## Install

Download `OpenBucket-v0.1.1-macOS.dmg`, open it, drag OpenBucket to Applications, and launch it from there. Requires macOS 26 or later.

This preview browses and downloads objects. Upload, delete, sync, and Finder mounting are not included. See the [compatibility notes](https://github.com/koative/openbucket/blob/main/docs/compatibility.md) for provider test status.
